About This Repository

This repository contains practical cybersecurity exercises, personal notes, and scripts developed while learning security fundamentals, analyzing attack techniques, and exploring defensive security concepts.

Areas of Focus

- Security Fundamentals
- Password Security and Hash Analysis
- Linux Security Tools
- Network Traffic Analysis
- Basic Malware Static Analysis
- Vulnerability Analysis and Detection
- Python Security Scripting

Learning Objectives

- Understand common attack techniques and their indicators.
- Practice security analysis in controlled lab environments.
- Develop basic detection and investigation skills.
- Document technical findings and lessons learned.
- Improve Python scripting for security-related tasks.

Lab Documentation

Each lab will document its objective, environment, tools, methodology, observations, and key takeaways where applicable.
